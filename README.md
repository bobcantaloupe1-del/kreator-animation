Kreator Animation Lab 🇹🇭
เว็บสตูดิโอแอนิเมชัน 2D ภาษาไทย รุ่น static มี workflow แบบโปรเจกต์/ฉาก/asset/ตัวละคร/พร็อพ/เสียง/ไทม์ไลน์ และปรับคุณสมบัติรายฉากได้ เปิดด้วยเบราว์เซอร์ ไม่ต้องติดตั้ง Node.js ไม่ต้องมี API key ไม่ต้องใช้ server และไม่เรียกบริการเสียเงิน
วิธีใช้ฟรีที่ง่ายที่สุด: เปิดไฟล์บนคอม
ดาวน์โหลดโปรเจกต์นี้เป็น ZIP จาก GitHub แล้วแตกไฟล์
เปิดโฟลเดอร์ `static`
ดับเบิลคลิก `index.html` เพื่อเปิดใน Chrome, Edge, Firefox หรือเบราว์เซอร์รุ่นใหม่
หน้า Animation Lab จะทำงานในเบราว์เซอร์โดยตรง ใช้ Canvas 2D วาดตัวละครและฉาก ปรับสีผิว/ผม/เสื้อ เลือก asset สำเร็จรูป เพิ่มฉากจากสคริปต์ วางตัวละคร/พร็อพ/ข้อความ/เสียง และปรับระยะเวลาบน timeline พร้อมบันทึกโปรเจกต์ใน browser storage การขยับปากใช้ระดับเสียงจากไมโครโฟนและอาจต้องอนุญาตไมค์
วิธีใช้ฟรีเพื่อเปิดเป็นลิงก์บนมือถือ/คอม: GitHub Pages
การเผยแพร่เว็บใช้ GitHub Pages ซึ่งให้บริการโฮสต์ static ฟรีสำหรับการใช้งานตามเงื่อนไขของ GitHub ต้องมีบัญชี GitHub และอัปโหลดไฟล์โปรเจกต์ขึ้น repository หนึ่งครั้ง จากนั้น GitHub Actions workflow ที่เตรียมไว้จะเผยแพร่โฟลเดอร์ `static` ให้อัตโนมัติ
สมัคร/เข้าสู่ระบบ GitHub และสร้าง repository ใหม่ เช่น `kreator-animation`
กด Add file → Upload files แล้วอัปโหลด `index.html` ภายในโฟลเดอร์ `static` (จะอัปโหลดไฟล์ทั้งโปรเจกต์ก็ได้)
เข้า Settings → Pages ของ repository
ในส่วน Build and deployment เลือก GitHub Actions
ถ้าอัปโหลดผ่านหน้าเว็บ GitHub โดยตรง ให้เข้า Actions แล้วเลือก workflow `Publish free web app to GitHub Pages` กด Run workflow หนึ่งครั้ง หรือ push การเปลี่ยนแปลงไป branch `main` ด้วย Git
เมื่อ workflow สำเร็จ GitHub จะแสดง URL ในหน้า Settings → Pages รูปแบบโดยทั่วไปคือ `https://ชื่อบัญชี.github.io/ชื่อ-repository/`
เปิด URL นั้นบนมือถือหรือคอมได้ทันที ไม่ต้องติดตั้งแอปหรือเครื่องมือพัฒนา
เก็บไฟล์ไว้ใน `static` ตามตัวอย่างที่ workflow ตั้งค่าไว้
ฟีเจอร์และข้อจำกัด
workflow สตูดิโอที่มีโปรเจกต์, หลายฉาก, asset library, ตัวละคร, ฉากหลัง, พร็อพ, ข้อความ, แทร็กเสียง และ timeline
ใส่บทพูด ทดลองเสียงภาษาไทยเมื่ออุปกรณ์มีเสียงภาษาไทยให้เลือก
ขยับปากโดยประมาณจากระดับเสียงที่ไมโครโฟนรับได้ ไม่ได้วิเคราะห์หน่วยเสียง/รูปปากภาษาไทยแบบ phoneme
ส่งออก WebM โดยเล่นผ่านฉากต่าง ๆ ตาม timeline ผ่าน MediaRecorder ในเบราว์เซอร์ที่รองรับ การบันทึกเสียงพูดลงไฟล์ไม่รองรับสม่ำเสมอ จึงอาจได้ไฟล์ภาพเคลื่อนไหวแบบไม่มีเสียง
ไม่มี generative image AI, โมเดล AI เขียนสคริปต์, rigging/animation ขั้นสูง, project cloud sync หรือ multi-scene final render; การแยกสคริปต์เป็นฉากใช้ตัวคั่นบรรทัดว่างแบบง่าย
เสียงพูดและ WebM ขึ้นกับเบราว์เซอร์และระบบปฏิบัติการ หากไม่มีเสียงภาษาไทยติดตั้งไว้ แอปไม่สามารถดาวน์โหลดเสียงเพิ่มให้เองได้ หน้าเว็บไม่มี API ภายนอกและไม่ส่งบทพูดไปยังเซิร์ฟเวอร์
สำหรับนักพัฒนาที่ต้องการใช้ dashboard เดิม
โฟลเดอร์ `src/` เก็บเวอร์ชัน Next.js ที่มี dashboard และ API บันทึกไอเดีย ซึ่งต้องติดตั้ง Node.js 20+ และ dependencies ด้วย `npm install` ก่อน ส่วนหน้า static ที่เปิดใช้ฟรีโดยไม่ติดตั้งเครื่องมืออยู่ใน `static/index.html` และเป็นเป้าหมายการ deploy บน GitHub Pages
